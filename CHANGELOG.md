# Changelog

## 0.1.0 — 2026-11-15

First public open edition of the chapter learning path.

- Shelf for documents, subtitles, public pages, and YouTube links that expose captions.
- Grounded pipeline: a concept or question is kept only when its quote is in the source.
- Study cycle with the next chapter locked until the current quiz is finished.
- Three-note memory sample that runs with no model key.
- Docker Compose, configuration docs, and CI for the API tests and the UI build.
