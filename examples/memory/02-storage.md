# Storage

Encoding decides whether a trace exists. Storage decides what happens to it after that. The two are easy to blur, because both can feel like "I studied this." They answer different questions. Encoding asks whether the experience got in. Storage asks whether the trace is still there when you come back.

Storage is the maintenance of a memory trace over time. A short-term trace fades in seconds unless it is rehearsed. Rehearsal keeps the trace available, but it does not by itself decide whether the trace will last until next week.

You can hear this difference in ordinary studying. You repeat a definition until you can say it back, look away for half a minute, and the sentence is already thinning. Another pass of rehearsal brings it back. That pass is doing real work: without it, the short-term trace does not wait. The same pass does not answer the question you actually care about on Thursday. Being able to hold a sentence while you are still looking at the chapter is not the same as being able to use it after a day away from the book. Rehearsal keeps the door open. It does not furnish the room.

What lasts across a delay is a different change. Consolidation stabilizes a trace so it can be recalled after a delay. The trace is reorganized, not merely held still. Material that was never encoded cannot be consolidated, because there is no trace to stabilize.

Stabilizing is not the same as gripping a sentence harder. The trace is reorganized: the claim is tied to the example, the example is tied to the question that will later cue it, and the whole thing becomes less dependent on the exact page where you first saw it. That is why a well-consolidated idea can be told in a new order. There is a hard limit on this, and it is easy to skip past. Consolidation has nothing to work on when encoding never happened. A chapter you scrolled through while thinking about something else does not become a stable memory overnight. There is no trace for the night to reorganize.

Sleep is the part people most want to treat as a shortcut. Sleep shortly after study supports consolidation of material you paid attention to. Sleep is not a substitute for encoding. It protects traces that attention already created.

A useful night, in these notes, has an order. You attend to a small set of claims. You tie each one to something you already know. Then you sleep. The sleep supports the traces attention already made. It does not go back and collect the pages you skipped, and it does not turn a familiar-sounding word into an idea you can explain. If a page never entered the trace, a full night leaves that page where it was.

When you plan a study day, separate the two jobs. Rehearsal is for the next minute: say it again before the short-term trace fades. Consolidation is for the delay: give a real trace time, and sleep, to become recallable later. Neither job can start from a page you never encoded.
