# Retrieval

A trace can be stored and still stay silent. You know you studied the chapter. The page looks familiar when you open it. The explanation does not come when the question is asked. The missing piece is often not another reading. It is a cue, and an attempt to use it.

Retrieval is using a cue to bring a stored trace back into mind. The cue can be a question, a diagram with a blank, or the start of an example. Without a cue that matches the trace, the stored idea can remain silent.

The cue has to meet the way the idea was stored. A question works when the question resembles the situation in which you will later need the idea. A diagram with one label missing works because the blank tells you which trace to search for. The first line of an example can do the same job: the scene starts, and the claim that belongs to that scene has a way back in. Rereading the full paragraph supplies every word, so it never asks the trace to come back. The idea can feel present while you are looking at it and then disappear as soon as the page is covered. Nothing was retrieved. The text was still in front of you.

Bringing the idea back is not just a test of whether storage worked. It changes the trace. A successful retrieval strengthens the trace more than rereading the same passage. This is called the retrieval practice effect. The effort of bringing the idea back is part of why the trace becomes easier to find next time.

The effort matters. An easy reread tells you the passage is still on the page. A question you can almost answer, and then do answer, tells the trace which cue leads to it. The next time that cue appears, the route is shorter. This is why closing the note and answering one question is a different activity from highlighting the same sentence again. Highlighting keeps your eyes on the source. Retrieval makes you leave the source and come back.

Attempts will fail. That failure is still part of the practice, provided the correction is timed properly. Feedback after a failed attempt tells you which cue was missing. The correction should arrive after the attempt, so the attempt itself still counts as retrieval. Reading the answer first turns the exercise back into rereading.

Read the answer first and you can nod along. You have seen the right sentence. You have not searched for it. The attempt is what makes the search happen; the feedback is what repairs the search when the cue was wrong or incomplete. Reverse that order and the exercise collapses into another reading of a passage you already had open.

A small way to use this note is to cover it and ask one question from each section before you look. If the answer comes, leave it. If it does not, give yourself the attempt, then uncover the sentence that names the missing cue. The attempt comes first. The source comes after.
